# SAIGE 0.1.0 Preview 1

This preview boots the C++20 engine on Windows x64 and draws a moving procedural 3D cube over a checkerboard ground. Move it with WASD or the arrow keys. Escape and the window close button exit.

## Run the Windows build

Extract the Windows x64 ZIP. From PowerShell, run `.\saige_desktop.exe --require-rendered`. A working Vulkan 1.3 driver and loader are required. For a bounded run, add `--frames 60`. Add `--validate` if the Khronos validation layer is installed. The strict mode exits with an error when it cannot render.

Run `.\saige_headless.exe --frames 60 --json` for a machine-readable, GPU-free smoke test.

## Build from source

Check out `v0.1.0-preview.1`. With Visual Studio 2022 and CMake 3.21 or later, run from the repository root:

```powershell
cmake --preset windows-release -DSAIGE_ENABLE_VULKAN=ON -DSAIGE_VULKAN_FETCH_HEADERS=ON -DVULKAN_HEADERS_ENABLE_MODULE=OFF
cmake --build --preset windows-release --parallel
ctest --preset windows-release
.\build\windows-release\Release\saige_desktop.exe --require-rendered
```

Linux core builds use the `linux-debug` preset. See [architecture and build instructions](https://github.com/devincombs2007-rgb/SAIGE/blob/b5ffac9b8f23a217925e74823cfbe2406232cbbe/README.md) and the [Vulkan verification guide](https://github.com/devincombs2007-rgb/SAIGE/blob/b5ffac9b8f23a217925e74823cfbe2406232cbbe/docs/windows-renderer-integration.md).

## Verification

All three CI workflows succeeded on release commit `b5ffac9b8f23a217925e74823cfbe2406232cbbe`:

- [Engine builds and tests](https://github.com/devincombs2007-rgb/SAIGE/actions/runs/44947724503) on Ubuntu and Windows Debug and Release, with a native MSVC x64 package.
- [Graphics checks](https://github.com/devincombs2007-rgb/SAIGE/actions/runs/44947724431) with Linux Vulkan/X11, sanitizer and native Windows build coverage.
- [Windows Lavapipe](https://github.com/devincombs2007-rgb/SAIGE/actions/runs/44947724457) with Khronos validation, Win32 swapchain lifecycle, moving-object readback and a strict desktop run. The image attachments are offscreen readbacks, paired with a separate swapchain presentation test.

## Known limitations

Physical Windows GPU and vendor-driver presentation remain outstanding in [#9](https://github.com/devincombs2007-rgb/SAIGE/issues/9). Windows and Linux rendering evidence uses CPU Vulkan via Mesa Lavapipe. The Windows binary ZIP does not bundle a Vulkan driver or validation layer. This preview is a procedural demo. Project persistence, textured glTF scenes, and the free camera are tracked for 0.2.
