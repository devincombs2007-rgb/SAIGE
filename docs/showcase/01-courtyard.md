# Showcase 01: Courtyard

A scripted run of SAIGE's capsule character through a PBR courtyard, rendered by SAIGE's own Vulkan renderer. It exists to exercise the
engine end to end (glTF import, material staging, HDR/metallic-roughness/normal-mapped/alpha-blended rendering, configurable lighting,
the capsule controller, the perf report) and to give a reviewer something to look at. It is not a game and not a benchmark.

## What is real

- **Renderer**: `SceneRenderer` with `hdr`, `ModelShading::MetallicRoughness`, sorted alpha blending and `SceneLighting`; assets go through
  `load_gltf_file` and `stage_model` (tangents are generated by the importer for the normal-mapped primitives).
- **Character**: `CapsuleCharacter` (PR #70) at the 60 Hz fixed step, driven by a waypoint script (`course.cpp`). It walks, sprints, jumps onto 0.5 m
  and 1.0 m crates, climbs three 0.2 m marble steps, drops off the dais, and runs into a wall and slides along it. Two runs are bit-identical
  (`showcase_course` test); the character never penetrates a collider; no ground flicker.
- **Non-box collision (new):** the ramp plaza near the south wall is collision made of triangles (PR #73 primitive, PR #74 controller support): a 25 degree
  wooden ramp the character walks up while grounded (ground normal z = cos 25 = 0.906 in the trace), a 1.4 m platform, and a 54 degree rusted-metal chute
  that is too steep to stand on. The script creeps onto the chute and the character slides to the floor. Stills `09_ramp_climb` and `10_chute_slide` show it.
- **Collision**: the same boxes and triangles that are drawn are in `scene.json`. Columns and barrels still collide as their bounding boxes (round colliders
  are not implemented; the triangle sweep could take a faceted prism).
- **Assets**: all generated by `generate_assets.py` from original code (numpy only): tileable PBR sets (albedo, normal, occlusion-roughness-metallic) for
  cobble, brick, wood, rusted metal and marble, plus the glTF scene. No third-party or AI-generated content.

## What is approximated or missing (do not read more into the images)

- **No real shadows and no image-based lighting.** One directional sun plus hemispherical ambient. The dark patches under objects are artist-placed
  blob decals (alpha-blended quads) and are fakes. Metals (gold/chrome spheres, rusted barrels) look dull because there is no environment to reflect.
- **No animation.** The character is a rigid capsule model with a forward lean from its speed; there is no skeleton or skinning.
- **Offscreen and scripted.** `saige_showcase` opens no window and takes no input. The "controllable character" is the controller API under test, not an
  interactive demo; wiring it to the desktop course is task E2 (`--capsule` behind an option on the #65 course) and is not done.
- **Software Vulkan.** Every image and video in the captures was rendered by Mesa lavapipe (a CPU rasterizer). They show correctness, not GPU speed.

## Run it

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DSAIGE_ENABLE_VULKAN=ON
cmake --build build
build/showcase/saige_showcase --out out --width 1280 --height 720 --ssaa 2          # stills + the whole camera sequence
build/showcase/saige_showcase --out out --stills 0 --sequence-seconds 0 --simulate-only   # course only, no GPU
python3 showcase/01-courtyard/capture.py --exe build/showcase/saige_showcase --out captures   # PNGs, mp4, gif, path plot (Pillow, ffmpeg)
python3 showcase/01-courtyard/generate_assets.py                                    # regenerate every asset
```

Tests: `showcase_course` (no GPU) and `showcase_smoke` (end to end; run with `SAIGE_REQUIRE_VALIDATION=1 xvfb-run -a ctest -R showcase`; exit 77 = no device).

## Engine changes this work produced

- `CapsuleCharacter` ground probe: a steep rim contact already touched at t = 0 no longer hides the floor beneath (grounded flickered every other tick and the
  feet bounced up to 8 mm when sliding along a ledge whose step-up is blocked). Regression test mutation-checked. On PR #70 (`fb2f109`).
- `SceneLighting` (PR #71): the sun and ground ambient are configurable and validated.
- `capsule_triangle.hpp` (PR #73): an exact swept vertical capsule against two-sided triangles, verified against a triangulated box and a brute-force reference.
- `CapsuleCharacter` on triangles (PR #74): ramps, crests, creases; and a fix for idle characters creeping down steep slopes instead of sliding (air braking).
