# Textured project fixture

Three project nodes share one original indexed glTF box. The middle node inherits its parent's scale and has a local rotation. The model carries an 8x8 RGBA checkerboard PNG and UV coordinates. Geometry and texture are generated by generate.py using the Python standard library. SAIGE authored the fixture, which is available under CC0-1.0.

Run saige_scene_asset_tool with saige.scene.json as its argument. The report counts project placements, CPU primitives, encoded images and encoded bytes. An invalid or missing model fails with an error. At this stage the tool validates CPU assets. It does not decode the PNG, allocate a GPU texture, or draw the scene.
