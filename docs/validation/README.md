# Engineering demonstration archive

Visual validation evidence for SAIGE technologies (the Continuous Visual Validation Program). Quality over presentation: these are stills, comparisons and short diagnostics that are meant to expose defects, never marketing. Numerical tests stay mandatory and are not a substitute; the director and the owner inspect results before anything is classified mature.

Each entry is a folder `YYYY-MM-DD-<technology>/` with a `README.md` that states, in this order: the exact engine commit, the technology, the test conditions (backend, adapter class, settings, how to reproduce), what was looked at, what was NOT looked at, known limitations, and the validation results. Every image is a JPEG small enough for a phone; clips (5 to 30 s MP4, 1080p where practical) are attached to the issue checkpoint rather than committed.

Rules kept in every entry:
* Software Vulkan (llvmpipe/lavapipe) results are correctness evidence only and are labelled as such; nothing here is physical-GPU or performance evidence unless the entry says so and names the hardware.
* "Looked at" means a person or I opened the image; "measured" means a test computed it. An entry never claims a visual review that did not happen, and never claims a listening.
* The delivered Showcase 04 film is not modified, re-rendered or remastered.
